# Sistema de Gestión Operativa - Florería "Alesli"

Este proyecto consiste en el desarrollo de un sistema de gestión integral diseñado para optimizar los procesos de registro de pedidos, control de inventario, gestión contable y administración académica de la florería "Alesli".

Stack Tecnológico
Lenguajes de programación: PHP, JavaScript, Python, HTML5, CSS3.
Frameworks: Laravel (PHP), Blade.
Herramientas de desarrollo: Lean-Kanban, Git/GitHub, Navegadores (Chrome, Firefox, Edge).

Base de datos
Motor de base de datos seleccionado: MySQL.
Gestión: Eloquent ORM.

Arquitectura 
Tipo de sistema a desarrollar: Sistema de Gestión Integral Web (ERP a pequeña escala) con módulo de automatización para WhatsApp.
Arquitectura seleccionada: Modelo-Vista-Controlador (MVC).

Funcionalidades Principales
Gestión completa del ciclo de vida de pedidos.
Control de inventario con alertas de stock mínimo.
Módulo contable de ingresos y egresos.
Administración de cursos de elaboración floral y alumnos.
Chatbot de WhatsApp para atención automatizada.
